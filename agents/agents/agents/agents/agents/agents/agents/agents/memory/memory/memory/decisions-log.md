# سجل القرارات

سجل القرارات المعتمدة أو المطلوب توثيقها بعد مراجعة بشرية. لا تسجل الأسرار أو بيانات العملاء الشخصية. لا يُعد هذا السجل بديلًا عن اعتماد شخص مخوّل.
