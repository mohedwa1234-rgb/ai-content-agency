# الذاكرة المشتركة

هذه الصفحة مرجع عمل موجز للوكلاء. حدّثها بمراجعة بشرية، ولا تضع فيها أسرارًا أو بيانات شخصية حساسة.

## الجمهور والموضوعات
- الجمهور الأساسي: يحدد لكل مهمة في موجز العمل.
- الموضوعات والقنوات: تحدد لكل حملة؛ لا تفترض تفضيلات غير موثقة.

## سير العمل
1. تحديد الهدف والجمهور والقناة.
2. البحث والتحقق عند الحاجة.
3. كتابة المسودة وإعداد الإنتاج.
4. مراجعة الجودة والحوكمة.
5. إعداد حزمة النشر وطلب اعتماد بشري صريح.

## تفضيلات مؤكدة
- تفضيل الأدوات والخدمات المجانية، مع الالتزام بحدود الاستخدام وسياسات كل مزود.
- عدم النشر أو إجراء أي فعل خارجي تلقائيًا.

## عناصر تحتاج تحديثًا
أضف هنا تفضيلات موثقة مع التاريخ والسياق، أو اترك القسم فارغًا حتى تتوفر معلومات مؤكدة.
