# أسلوب الشركة

## الصوت والنبرة
واضح، مهني، ودود، ومباشر. نفضّل لغة طبيعية ومحددة على المبالغة والعبارات التسويقية الفارغة.

## قواعد التحرير
- اكتب بلغة الجمهور والمنصة، وبالعربية الفصحى المبسطة ما لم يطلب موجز المهمة غير ذلك.
- ابدأ بالفائدة أو الفكرة الرئيسية، واستخدم عناوين وقوائم عند تحسين قابلية القراءة.
- افصل الحقائق عن الرأي والافتراض. أضف المصادر للمعلومات القابلة للتحقق.
- لا تختلق أرقامًا أو شهادات أو تجارب أو ضمانات.
- استخدم دعوة واضحة وغير ضاغطة إلى الإجراء.
- تجنب التمييز والوصم والوعود الصحية أو المالية أو القانونية غير المسندة.

## إعدادات خاصة بالمهمة
المنصة، اللهجة، طول النص، والمصطلحات المفضلة تُحدد في موجز كل مهمة؛ لا تفترضها مسبقًا.
